# Superstore Profitability Dashboard 📊
**🚀 Live Interactive Dashboard:** https://datastudio.google.com/s/mdfiyk8GHX4

![Dashboard Screenshot](dashboard.png)

## Business Problem
9994 orders me se kaunsi Category loss me hai? Kaunsa Region sabse profitable hai?

## Key Insights
- **Total Orders:** 9,994 | **Loss Orders:** 1,871 (18.7% orders loss me)
- **Profit Margin:** 12.5%
- **Most Profitable Region:** West - 37.9%
- **Least Profitable Category:** Furniture - Only 18k profit vs Tech 145k
- **Interactive Feature:** Region-wise filter for deep analysis

## Tools Used
Excel (IF, Pivot) | Python (Pandas) | Looker Studio

## Recommendation
Furniture ki pricing + shipping cost revise karne se 15% profit badh sakta hai.
